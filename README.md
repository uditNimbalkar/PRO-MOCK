# AI Mock Interview Platform

This workspace contains the initial project setup for:

- Frontend: Nuxt 3 + Vue + Vuetify
- Backend: Java Spring Boot

## Structure

- `frontend/` - Nuxt application
- `backend/` - Spring Boot application

## Quick start

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
./mvnw spring-boot:run
```

> If `mvnw` is not executable on Windows, use `mvnw.cmd spring-boot:run`.
